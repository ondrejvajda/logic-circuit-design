# Logic Circuit Design

Interactive web tools for learning, designing, and simulating digital logic circuits.

Created for the *Základy digitálních systémů* (Fundamentals of Digital Systems) course to help students practice the process of designing combinational logic circuits, from truth tables and Karnaugh maps to circuit implementation.

## Features

The project includes three interactive tools:

### Truth Table
- Create and edit truth tables with 2–5 input variables.
- Define up to 6 output functions.
- Practice completing truth tables and check your answers.
- Export tables as PNG images.

### Karnaugh Maps
- Create Karnaugh maps for 2–5 variables.
- Group cells to simplify Boolean expressions.
- Check solutions and practice Boolean algebra.
- Export maps as PNG images.

### Logic Circuits
- Design circuits using NAND and NOT gates.
- Create and connect interactive logic gate schematics.
- Simulate wiring on a virtual circuit board using 74xx logic ICs.
- Test circuits against all 16 input combinations.
- Track logic gate usage.

## Getting Started

No installation or build process is required.

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Select a tool and start practicing.

The application is built with **HTML, CSS, and JavaScript** and runs directly in a modern web browser.

> The user interface is in Czech.
